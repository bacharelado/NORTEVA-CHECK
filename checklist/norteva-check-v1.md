# NORTEVA CHECK — Checklist v1

## Identificação
- [ ] Cliente e responsável registrados
- [ ] Escopo definido
- [ ] Autorização arquivada
- [ ] Janela de avaliação definida

## Exposição externa
- [ ] Domínios autorizados confirmados
- [ ] DNS revisado
- [ ] Subdomínios conhecidos revisados
- [ ] Serviços publicamente expostos registrados
- [ ] TLS/HTTPS revisado

## Identidade e acesso
- [ ] MFA avaliado para contas críticas
- [ ] Contas administrativas identificadas
- [ ] Contas antigas/inativas verificadas
- [ ] Princípio do menor privilégio avaliado
- [ ] Política de senhas avaliada

## Sistemas e dispositivos
- [ ] Sistemas suportados/atualizados
- [ ] Antivírus/EDR avaliado quando aplicável
- [ ] Bloqueio de tela avaliado
- [ ] Inventário básico existente

## Backup e continuidade
- [ ] Backup identificado
- [ ] Periodicidade verificada
- [ ] Cópia separada/isolada avaliada
- [ ] Teste de restauração discutido

## E-mail e dados
- [ ] Proteções de domínio/e-mail revisadas
- [ ] MFA para contas críticas avaliado
- [ ] Procedimentos contra fraude por e-mail avaliados
- [ ] Dados sensíveis identificados em alto nível
- [ ] Acesso a dados revisado

## Resultado
- [ ] Evidências organizadas
- [ ] Achados validados
- [ ] Prioridades atribuídas
- [ ] Plano de correção preparado
- [ ] Relatório revisado antes da entrega
